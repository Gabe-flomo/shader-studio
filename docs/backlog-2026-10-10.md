## Texture builder (new node)

A node that holds **its own shader graph, rendered as a texture**. Opening it gives its own canvas and renderer. The result is a texture you can wire anywhere: food for slime, a grid's start, a mask, a material. ("Create new texture" vs "load a texture".)

## Other builders: rebuild them like the Agent Builder

- **Grid Rules:**
  - the viewport-first layout with settings at the side;
  - draw Born and Alive counts on a real grid and step through to try them before building;
  - **Stencils** need a visual that makes sense;
  - **Blocks:** a before/after per rule (a fixed grid flashing from one state to the next) rather than an animation, so you see each rule and then combinations;
  - **step through frames** in every simulation;
  - the **Waves** template is far too fast by default;
  - the **Smooth** settings are confusing ("I don't know what half of these mean").
- **Simulation builder (bigger idea):**
  - stack rules on a base (e.g. start from Game of Life, add "two cells colliding explode into N copies");
  - conditions: collisions, direction, crowding, clusters;
  - actors, behaviours and conditions, as a standard simulation toolkit;
  - some may suit JavaScript layers better (bouncing balls that grow or shrink when they collide, spawn within bounds…).
- **2D Scene Builder: more customisable space warping.**
  - **Transform blocks:** each is three lines in Expression Block style: `uv.x = …`, `uv.y = …`, `uv = …` (any can be left as it is), with assign operators.
  - **Variables:** x, y, uv and t are available everywhere, so you can type Graphtoy-style expressions (`sin(x + t) * y`).
  - **A library of transforms**, like an audio plugin's effect list (trigonometric, exponential, ripples, fractal or recursive repeats…), found by auditing real shaders for patterns.
  - **Random:** offers three options to pick from, not one.
  - **Stacking:** feed each block's uv into the next, or **combine** blocks (add, subtract, multiply, blend: "a copy of uv multiplied back into uv").
  - **Draw on UV space** to warp it.
- **3D Scene Builder:** restructure it to be clearer about what you can build.
- **Mobile:** keep the app as it is, but make the builders mobile friendly.
