# Plan for the 2026-10-10 notes

This plan turns `docs/backlog-2026-10-10.md` into PR-sized steps, in a suggested order. The user picks
or reorders. Each step is one PR with tests and a browser check. Steps in the same wave touch different
code, so they can run side by side.

## In progress

| | What | Branch |
|---|---|---|
| A | **Depth, finished:** link a light to a scene object (several lights); the picture as the environment; an experimental-models mode (DA2 Base, MiDaS, DA3 Small, Depth Pro; ZoeDepth if it loads) | `claude/depth-finish` |
| B | **Unified Texture node:** image, video and texture, image URLs, editing, saved graphs keep their pictures, webcam with mini-Play and hand tracking, Generate depth | `claude/texture-node` |

## Wave 1: fixes you'll hit every day (small)

1. **Context restore crash.** "Cannot set properties of undefined (setting 'value')" after the WebGL context comes back: rebuild every uniform the frame loop sets, drop old-context objects (timer queries, deleted textures), and test a forced context loss.
2. **Agent Builder fixes:**
   - the How-far-ahead slider jumping and resetting;
   - the diagram's walker wraps instead of leaving the picture;
   - **Surprise me** back in the builder;
   - start page: "clear the current graph?";
   - opening the builder with a builder-made group in the graph: **Edit this one / Start over / Add another**;
   - no fallbacks to the old rules editor.
3. **Node placement:** everything added from builders, the Do bar, recipes and cards lands **at the viewport**. Convert and Auto layout keep graphs compact (no lone column far to the left).
4. **Expression Block tidy-up:**
   - remove "+ Note / + Description / Edit" from the card;
   - the description lives in the editor;
   - **Edit in Function Builder** only on blocks it made;
   - **select a number → make it a slider/input** (Expression Blocks, Custom Functions, any code).
5. **Do-bar agents dialect:** it must read back the recipe it prints (the screenshot's dozens of "agents takes key=value settings").

## Wave 2: saving and files

6. **Saved graphs by time:** Today, This week, Earlier, scrolling inside the list.
7. **Autosave:** every ~5 minutes as a new minor version, once a graph has been saved, on by default and ending when you leave the graph (or for a set time). It uses the series code.
8. **Web export, small:** export the GLSL plus only the JavaScript it needs (the page player for passes, agents or video only when used), as an embeddable snippet with the full page as an option. Today it's ~28,000 lines.

## Wave 3: the Agent Builder, further

9. **Direct manipulation on every diagram:**
   - sensors: drag sideways for the angle, outward for the distance;
   - Born: drag to move, handles for radius or size, reposition a point;
   - turn and wobble arcs;
   - the view ring;
   - force arrows;
   - fields.
10. **Wiring into a group, three ways:** wire from the graph, from a group, or **create a new group** for any input (food, masks, start).
11. **Text as shape or wall**, for slime, grids and agents, in the shader's own style.

## Wave 4: textures and programs

12. **Texture builder:** a node holding its own shader graph, rendered as a texture with its own canvas, wireable anywhere (food, masks, starts, materials). It builds on wave 3's "create a new group".

## Wave 5: rebuild the other builders on the Agent Builder's shell

13. **Grid Rules on the shell:**
    - a viewport-first layout;
    - draw Born and Alive counts on a real grid, then step through and play to try them;
    - Blocks as before/after per rule;
    - a Stencils visual that makes sense;
    - step through frames everywhere;
    - Waves template slower;
    - Smooth settings reworded.
14. **2D Scene Builder space blocks:**
    - transform blocks of three lines (`uv.x = …`, `uv.y = …`, `uv = …`) with assign operators;
    - x, y, uv and t available everywhere (Graphtoy-style expressions);
    - a library of transforms from a shader audit (trig, exponential, ripples, recursive repeats);
    - "random" offers three choices;
    - blocks chain (uv flows on) or **combine** (add, multiply, blend);
    - later: draw on UV space.
15. **3D Scene Builder restructure:** clearer about what you can build, on the shell.
16. **Builders on mobile:** the shell's drawers become phone-friendly.

## Wave 6: simulations

17. **Simulation builder:**
    - stack rules on a base (Game of Life + "colliding cells explode into N");
    - conditions: collisions, direction, crowding, clusters;
    - actors, behaviours and conditions as a standard toolkit;
    - some live better as JavaScript layers (bouncing balls that grow on collision, spawning within bounds): plan which go where.

## Wave 7: Play, signals and MIDI

18. **Built-in signals:** how many signals there are, and how many are active.
19. **MIDI note mapping that wraps octaves** (12 notes → 12 targets in any octave).
20. **MIDI and mapping fixes:** the user will describe them.

## Wave 8: groups

21. **Consistent group sockets:**
    - one look and one way to add inputs and outputs across Agents, March Loop and Scene groups;
    - Scene Pos / Scene Output only inside a 3D render;
    - a 3D shape added on its own creates its Scene.
